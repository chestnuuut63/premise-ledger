# RSI：让账本自己发现「该记哪些字段」

课程第 5 讲把 RSI 定义为**优化机制本身成为优化对象的回路**，三个要素是自我指涉、经验门控、递归；两个护栏是信号解耦与固定预算。这个目录是它的一个受限实现。

```bash
python rsi/run_rsi.py --budget 100
```

十秒跑完，输出两折的迭代日志与终局。

---

## 一、为什么改进对象是「字段」而不是「检测器」

一开始想到的是让 agent 去改检测器代码。实测发现这条路在这份数据上走不通——`evaluate.py` 里 B 组拿到的 8/13，是 `build()` 把 `symbol`、`unresolved`、`exported` 三个字段清空了，**不是检测器变弱**。检测器再怎么写也抓不到数据里不存在的字段。换而言之：

> 这不是算法问题，是表示问题。能改的东西只能是表示本身。

所以可编辑表面被定义为六个字段开关：

| 字段 | 记什么 | 没了它，哪类病抓不到 |
|---|---|---|
| `deps` | 依赖边（谁靠谁） | 孤儿结论、幽灵引用、循环论证、污染传播 |
| `symbol` | 符号表（同一量能否被认出是同一个量） | 前提漂移 |
| `inputs` | 输入清单 | ——（是 `unresolved` 的来源） |
| `unresolved` | 未解析输入 | 孤儿输入 |
| `exported` | 对外标记 | 交付门禁 |
| `alts` | 替代支撑边 | ——（只影响结论状态） |

搜索空间 2⁶ = 64 种组合。

## 二、回路怎么走

按讲义的双层结构：

- **内层**：对现任者做单点变异（翻转一个字段），在**训练折**上评估，按公开分数排序，提交前 3 名。
- **外层**：这 3 个候选在**留出折**上评估，私有分数做 argmax；只有赢过现任者才上位。
- **预算**：每折总评估次数封顶（默认 80），不能靠多跑取胜。
- **数据**：10 段对话按前后各 5 段分两折，互为训练/留出。

信号解耦体现在：内层筛候选时看不见留出折；留出折只回答「谁上位」。所以 agent 想被选中，只能靠在没见过的对话上也真的好。

## 三、结果（`--budget 100`）

| 折 | 训练 → 留出 | 路径 | 终局私有检出 |
|---|---|---|---|
| 1 | D01–D05 → D06–D10 | 14.3 → 57.1 → 71.4 → 85.7 → **100.0** | 100.0% |
| 2 | D06–D10 → D01–D05 | 16.7 → 66.7 → 83.3 → **100.0** | 100.0% |

每一次跃升都对应一个字段：

- `+依赖边` 一步把检出从 15% 抬到 57–67%（孤儿结论、幽灵引用、循环论证、污染传播同时被点亮）
- `+符号表` 抓到前提漂移
- `+未解析输入` 抓到孤儿输入
- `+对外标记` 抓到交付门禁（折 1）

## 四、三个值得讲的发现

**① 它自己发现了「三件东西」，而且顺序和人工设计一致。**
依赖边 → 符号表 → 未解析输入 → 对外标记，与海报第 10 页「B 到 C 多出来的三个字段」完全对应。区别只在于：这次是搜出来的，不是人设的。

**② 「替代支撑边」两折都没有被采纳。**
它不改变检出率，只改变结论的状态（`invalidated` 还是 `degraded`）。而评分函数只看检出率，所以搜索判定它无用。

> 这正是第 5 讲课后思考题说的：评分函数 `g` 相当于进化中的环境。**`g` 看不见的价值，自我改进也发现不了。**

**③ 折 2 没发现「对外标记」，因为它的留出折没有交付门禁埋点。**
留出集没覆盖到的能力，搜索没有信号去发现它。这说明评测集的设计直接决定自我改进的方向——和 ② 是同一件事的两面。

## 五、边界（必须写在前面）

1. **这是受限自我重写，不是任意代码重写。** 可编辑表面被限定在六个字段开关上；让 LLM 直接改检测器代码需要模型在环，本实验没有做。
2. **外层是搜索，不是生成。** 候选来自单点变异，不是模型提出的新规则。
3. **样本小。** 10 段对话、13 处埋点，两折各 6–7 处，统计上只能做定性判断，不能当基准。
4. **严格说不是盲测。** 作者读过全部对话，留出折的语义内容是知道的；脚本层面做到了隔离（内层不读留出折分数），认知层面做不到。这一点与 A/B/C 消融的自评局限同源。
5. **饱和。** 人工设计的完整账本已经是 100%，所以本实验的价值不在提分，而在「用更少的字段达到同样效果」——它把六个字段里的四个识别为必要，两个识别为非必要。

## 六、与课程内容的对应

| 第 5 讲的概念 | 本实现 |
|---|---|
| 自我指涉 | 改的是账本自己的字段集，同一套代码库 |
| 经验门控 | 能否上位由留出折的可测分数决定，不是「觉得更好」 |
| 递归 | 被接受的基因组成为下一轮变异的基座 |
| 信号解耦 | 内层筛候选只用训练折，留出折只做 argmax |
| 固定预算 | `--budget` 封顶，禁止靠多跑取胜 |
| 双层优化 | 内层在训练折上优化，外层在留出折上选择 |
| `g` 即环境 | 见发现 ②：评分函数决定了搜索能看见什么 |

## 七、它和 premise-ledger 什么关系

这是同一个东西的两面：**账本管「结论站在哪些前提上」，RSI 管「这套记账方式本身还能不能更好」**。

一次自我改进也是一条结论——「新字段集更好」——它也依赖前提：留出折没参与筛选、预算没超、评测器没改。这些前提写进账本，就是 RSI 回路自己的门禁。换句话说：

> 递归自我改进最需要记账，因为它是唯一一种「改写者与被改写者是同一个东西」的场景。
